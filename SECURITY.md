# Security Policy

## Supported versions

`devcard` is currently pre-1.0 and best treated as a fast-moving local tool.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| < 0.1.0 | No |

## Reporting a vulnerability

Please do **not** file public issues for suspected vulnerabilities.

Instead, open a private GitHub security advisory or contact the maintainer through a private channel first. If no private path is visible, open a minimal public issue asking for a secure reporting route **without** posting exploit details.

## Scope

In scope:

- unsafe default behavior in `devcard`
- accidental data disclosure through generated output
- hidden network access or telemetry
- supply-chain or release-process issues in this repository

Out of scope:

- vulnerabilities in downstream READMEs generated by user-edited content
- general support questions
- feature requests framed as security issues

## Response expectations

This is an open-source side project, so response times are best-effort. Good reports with clear reproduction steps help a lot.

## Safe disclosure notes

Please include:

- affected version
- reproduction steps
- likely impact
- suggested mitigation if you have one
